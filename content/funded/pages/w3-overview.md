::: intro
This week you write one sentence that is true and leaves something out. A
generator turns your choice into a working tool. Three classmates get that code
with no label on it, and you get theirs.
:::

::: objectives
By the end of this week you will be able to:

1. Read a short Python tool and say what it reaches and what it changes.
2. Point at the line in a record that shows it, not at what the agent said.
3. Say which tools you would not let run unattended, and give the reason.
:::

::: scope | Authorization and Scope
You have three permitted targets this term: the practice target this course
supplies, the agent you built, and the school gateway. Nothing else.

This week adds one rule. A classmate's tool runs only inside the supplied
sandbox, and only against your own agent. You never hand a tool to a classmate
yourself; the course distributes them. Never a commercial AI service. Read the
Rules of Engagement page in Start Here before you run anything.
:::

::: callout time | How long this should take
| Part | Hours |
|---|---|
| Reading the lesson | 1.0 |
| Picking your effect and writing the description | 1.5 |
| The discovery session | 0.75 |
| Probing and reading the code after it | 2.0 to 3.0 |
| Writing the three reports | 1.5 to 2.0 |
| **Total** | **6.75 to 8.25** |

Students new to programming often take two to three times as long on the code
reading. That puts a realistic week between about 10 and 20 hours. If one tool
defeats you, say so in the report and move on. A defeat you can explain earns
more than a guess.
:::
