::: intro
This week you put a price on the loop. You predict what a runaway agent costs in
cents, run one, and watch the budget bar drain. Then you fill in the cap that
stops it, and the gate that stops more than you meant.
:::

::: objectives
By the end of this week you will be able to:

1. Predict what a run will cost in cents, then check that against the ledger.
2. Fill in a cap that ends a run before it spends past a number you set.
3. Say what an approval gate blocks, including the work you wanted done.
:::

::: scope | Authorization and Scope
Three permitted targets this week, and nothing else:

1. The practice target this course supplies.
2. The agent you built.
3. A model reached through the school gateway, using your own token.

The runaway runs on a burnable key your instructor issues. It has a small
ceiling and it is meant to be spent. Never point it anywhere else, and never use
another student's key. Clause 3 of the Rules of Engagement page in Start Here
covers tokens.
:::
