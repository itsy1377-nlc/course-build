::: intro
Week 1 has two jobs. You get your tools working, and you learn what an agent is
before you build one.
:::

::: objectives
By the end of this week, you will be able to:

- 1.1. Explain in plain language what an agentic system is.
- 1.2. Explain why an agent fails differently from ordinary software.
- 1.3. State what you may attack in this course, and why scope comes before
  technique.
- 1.4. Read short Python code and predict what it prints.

These serve course outcomes O5 (working inside an authorized scope) and O1
(scripting against a model API).
:::
