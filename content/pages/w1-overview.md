::: intro
Week 1 has two jobs. You get your tools working, and you learn what an agent is
before you build one. Nothing this week needs an API key.
:::

::: objectives
By the end of this week, you will be able to:

- 1.1. Explain in plain language what an agentic system is.
- 1.2. Explain why an agent fails differently from ordinary software.
- 1.3. State what you may attack in this course, and say why scope comes before
  technique.
- 1.4. Read short Python code and predict what it prints, using variables,
  strings, lists, and dictionaries.

These serve course outcomes O5 (working inside an authorized scope) and O1
(scripting against a model API). The six are on the Welcome page.
:::

::: scope
You attack nothing this week. You still read the Rules of Engagement page, and
you are still graded on it.

That order is on purpose. You learn what you are allowed to do before you learn
how to do anything.
:::

::: callout stop | The Module 0 Gate is due on day 3, and it is not optional
The Module 0 Gate is this course's attendance check. The college requires every
fully online course to verify attendance by the third class day. This quiz is
how yours is verified.

**If you do not complete it by day 3, you can be dropped from the course.** That
is a records action, not a grade. Nobody can fix it for you afterward.

The Gate does three things at once. It verifies your attendance. It grades your
reading of the Rules of Engagement. It proves your environment works.

You get unlimited attempts and you need every question right. Start it on day 1.
:::

::: callout note | You do not need an API key this week
Week 1 installs nothing except a Python virtual environment. The lab code ships
with an offline provider called `mock`. It runs with no key, no internet, and
no waiting.

Lab 1 is built to be finished that way. You add a key in Week 2.
:::

::: callout time | About how long this takes
The Start Here module and the Rules of Engagement: about 90 minutes.

Setup and `verify_env.py`: 1 to 2 hours.

The Week 1 content page: about 45 minutes.

Lab 1: about 2 hours.

That is 5 to 6 hours of assigned work in total.

If programming is new to you, the coding parts commonly take two to three
times as long. That wider range is normal, not a sign of falling behind.

Setup is the part that goes wrong. It is the main reason students fall behind in
week 1. If you are stuck for more than 30 minutes, post the whole output on the
Q and A board and keep going with the reading.
:::
