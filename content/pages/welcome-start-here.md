::: section | What this course is
This course is about agents, and about how they break.

An **agent** is a program that lets a language model call your code. You ask it
a question. It picks one of your functions and runs it. Then it uses the result
to answer you.

That design is useful. It is also a new place for attacks to land.

You work with one small agent all term. You do three things with it:

1. You extend it, so it can talk to a model and use tools.
2. You attack it, so you can see how it fails.
3. You test it, fix it, and prove the fix held.

You never build any of this from an empty folder. You read working code, change
the parts that are marked, and test what you changed.
:::

::: section | What you will be able to do
By the end of the term, you will be able to do these things:

- Write a script that calls a language model and handles its errors.
- Add a tool of your own design to a working agent.
- Name three ways an agentic system gets attacked, and show one of them.
- Run a test harness against an agent and read what it reports.
- Write a security finding you could hand to an employer.
- Check code an AI wrote before you trust it.

Those six skills are the official course outcomes. Here they are in the exact
words the college uses:

| # | Outcome |
|---|---|
| 1 | Automate interaction with language model APIs using scripts, including request construction, response parsing, and error handling. |
| 2 | Configure and extend an agentic system that integrates a language model with external tools. |
| 3 | Identify security weaknesses in agentic systems, including prompt injection, excessive agency, and insecure tool authorization. |
| 4 | Execute and extend a structured test harness against an agentic system and interpret the results. |
| 5 | Document security findings and apply remediations within defined authorization boundaries. |
| 6 | Evaluate AI-generated code and output for correctness before use. |
:::

::: callout time | How this course runs
This course is **fully online and fully asynchronous**. Nothing meets live.
There is no class you have to attend at a set hour.

Work is due **Sunday at 11:59 PM Central**, unless a page says otherwise.

Assigned work runs about **5 to 9 hours per week**, reading included. Every
Overview page itemizes its own week, so plan from those numbers.

Coding takes longer when it is new. Students with no programming background
commonly spend two to three times the assigned time on the coding parts. That
puts a realistic week between about **10 and 20 hours**.

That range is normal. It is not a sign of falling behind. This is a short term
carrying a full course, so block the wider figure and adjust down.
:::

::: section | Do these four things in your first three days
The Gate is first because it has the earliest deadline. Steps 2 and 3 are how
you pass it.

1. **Take the Module 0 Gate. It is due on day 3.** It has three parts: a quiz
   on the Rules of Engagement, a code you get from your computer, and a short
   written answer. You get unlimited attempts, and only your best score counts.
2. **Read the Rules of Engagement page, all of it.** It says what you may
   attack and what you may never attack. The Gate quiz comes straight from it.
   You have to score 100 percent to open Week 2.
3. **Set up the lab repository and run the checker.** The setup guide is in the
   repository. Run `python verify_env.py`. It prints a short code. Paste that
   code into the Gate.
4. **Read the rest of this module.** The AI Use Policy and the Course Schedule
   matter most. Both are short.

Then post in the Introduce Yourself discussion. That one is due on day 7.
:::

::: callout stop | Why day 3 is a hard date
The Module 0 Gate is your **attendance verification** for this course. Alamo
Colleges requires every fully online course to have an activity finished by the
third class day. Census falls on day 8 in almost every session.

If you do not finish the Gate, you can be reported as never having attended.
That affects your enrollment in the course.

Start it on day 1. Do not save it for day 3.
:::
