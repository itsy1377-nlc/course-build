::: intro
This week you run your first real attack. You already built an agent that can
read tickets and send email. Now you find out what happens when someone writes
a ticket on purpose to steer it.
:::

::: objectives
By the end of this week, you will be able to:

- 5.1. Explain the difference between direct and indirect prompt injection.
- 5.2. Run an attack against the lab target and collect evidence of what it did.
- 5.3. Explain why a rule written in the system prompt is not a control.
- 5.4. Write one finding on the report template, with evidence and a
  framework reference.
:::

::: scope
Everything this week runs against the HelpDesk Lite app on your own computer.
Nothing else. Read the Rules of Engagement again before you start, especially
clause 2.

If you find yourself typing a web address that is not `127.0.0.1`, stop.
:::

rather than on the attack. Post on the Q and A board early.
