::: intro
This week the direction flips. Until now your script called the model, and from
here the model calls your function.
:::

::: callout stop | The hardest week, and it is built so you cannot fall out
Five protections are already in place.

| Protection | What it gives you |
|---|---|
| Pass or fail checkpoint | Code that will not run still passes, on time |
| `agent-working` branch, day 18 | A working version, three days before the deadline |
| Reading capped at 45 minutes | The Annotated Skeleton, and nothing else |
| Nothing else needs working code | The checkpoint is the only graded item |
| Pinned errors thread, day 15 | "Top 10 Week 3 Errors" on the Q and A board |
:::

::: objectives
By the end of this week, you will be able to:

- 3.1. Describe the difference between calling a model and a model calling you.
- 3.2. Explain what a JSON tool schema is, and what a model learns from one.
- 3.3. Apply try, except, a timeout, and a retry to code in the lab scaffold.
- 3.4. Walk through the agent loop and say what each part does.

These serve course outcomes O1 (scripting against a model API), O2 (extending
an agent with tools), and O6 (checking AI-written code).
:::

::: callout time | About how long this takes
The content page: about 45 minutes.
The Annotated Skeleton reading: 45 minutes, and it is capped there.
Hands-on work in the lab: about 4 hours.
The checkpoint write-up: about 30 minutes.

That is about 6 hours of assigned work in total. This is the hardest week, and
not the longest: weeks 4 and 7 both assign more hours.

If programming is new to you, the coding parts commonly take two to three
times as long. That wider range is normal, not a sign of falling behind.
