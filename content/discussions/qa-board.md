::: intro
Ask anything here about the course, the labs, or an error you cannot get past.
It is not graded, it stays pinned all term, and your instructor answers within
one business day.
:::

::: callout stop | Never post an API key
A key is a credential, and so is a password or a token. Never paste one into a
post, a reply, or a code block.

**Never post a screenshot that contains one.** A key is easy to miss in a
terminal window, an editor tab, or a settings file. Look at every line of an
image before you attach it.

If a key does end up here, act the same minute. Turn it off at the provider,
make a new one, and message your instructor. Nobody is in trouble for reporting
a leak quickly.
:::

::: steps | How to ask so it takes one reply, not four days
1. **What you were trying to do.** One sentence.
2. **What you actually ran.** The exact command, in a code block.
3. **What you expected to happen.** Half the questions here turn out to be a
   correct result that looked wrong.
4. **What happened instead.** The exact error text, pasted, not summarized.
5. **Your operating system and your Python version.**

Give the post a title that names the problem. "Harness says no module named
harness" is findable. "Help please" is not.
:::

::: section | How to answer somebody else
Answering is the fastest way to learn this material.

- **Point, do not paste.** Name the file and the idea. Do not hand over your
  code for a graded module.
- **Say how you know.** "I hit this too, and it was my virtual environment"
  helps more than a bare command.
- **Be kind about basics.** Half the class had never opened a terminal before
  this course.

You may share how something works. You may not share your code, your results,
or your quiz answers.
:::
