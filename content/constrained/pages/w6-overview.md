::: intro
Last week you made a call and recommended a containment. This week you build it,
twice. First as a sentence in the agent's prompt. Then as code at the tool
boundary. You measure both, the same way, and the two numbers make the argument.
:::

::: objectives
By the end of this week you will be able to:

1. Build a control at your agent's tool boundary, in code.
2. Measure the same case before and after, five trials each time.
3. Show that your control still lets legitimate work through.
:::

::: scope | Authorization and Scope
You have three permitted targets this term and no others:

1. The practice target this course gives you.
2. The agent you build.
3. A language model running on your own computer.

Never a commercial AI service. Never a system you do not own. The Rules of
Engagement page in Start Here holds the full policy, and it applies to every run
you make this week.
:::
