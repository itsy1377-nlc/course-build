::: intro
This week you ask one question and answer it with a count. Does the agent do the
same thing twice? You send one request five times, then five different requests
once each, and compare all ten runs.
:::

::: objectives
By the end of this week you will be able to:

1. Explain why two runs of the same request can end differently.
2. Compare a set of runs on features you read off the record.
3. State what five trials can tell you, and what they cannot.
:::

::: scope | Authorization and Scope
The permitted targets are the same as week 1. You may work with the practice
target this course gives you, the agent in your own lab folder, and a model
running on your own computer.

Never a commercial AI service. Never a system you do not own. The Rules of
Engagement page in Start Here holds the full list.
:::

with code in them. That puts a realistic week between about 10 and 15 hours. If a
run fails and you cannot see why, post the exact error text on the Questions and
