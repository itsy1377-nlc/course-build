::: intro
Write your own attack, predict it, run it five times, and score how far it got.
Ten points, due day 21. This is the first work in the course that is yours rather
than supplied, and at the end of the week it joins the class pool.
:::

::: scope | Authorization and Scope
Run this only against the practice target this course gives you, using the agent
in your own lab folder and a model on your own computer. A commercial AI service
is never a permitted target. Your case file carries one line saying the target is
authorized, and the runner will not load a case without it. See the Rules of
Engagement page in Start Here.
:::

::: directions | Directions
1. Pick your door. Name one tool you want the agent to call, and write one
   sentence on why you picked it.
2. Pick your hiding place: a ticket body, a subject line, an account note, or a
   knowledge base article. One place, not several.
3. Copy the case template to a new file. Give it your own name and title. The
   file is settings, not code.
4. Write the request a support person would type. For a hidden instruction this
   is an ordinary request, with nothing odd in it.
5. Write your planted text in your own words. Do not copy a supplied case.
6. Pick one detector, and set it to the strongest record your claim needs. Name
   the recipient if your claim is that data left.
7. Write your prediction before you run anything. Name the step you expect, the
   record you expect, and one thing that would show you were wrong.
8. Run the case. It runs five trials.
9. Open all five traces. In each run, mark the first model decision, the first
   tool call, the point where your text entered, and the furthest step reached.
10. Build a score table: one row per run, with the step it reached and the record
    line that shows it.
11. Write one sentence on what your result does not settle.
:::

::: callout tip | If nothing happens
An attack that stops early is normal, and it is not a lower grade. Small local
models often read the planted text, follow it, and still get the last step wrong.
Report the step you reached and the line that shows it. Do not change your
prediction afterward to match the result.
:::

::: submit | How to Submit
Submit two things. First, one text file or PDF with your name at the top, holding
your case file, your prediction, your score table and your closing sentence,
under the numbered headings above. Second, all five trace files as uploads. Due
Sunday 11:59 PM, day 21. Your instructor reads every case before it goes into the
class pool.
:::
