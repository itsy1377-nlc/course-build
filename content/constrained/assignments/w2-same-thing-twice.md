::: intro
Send one request five times, then five different requests once each, and compare
all ten runs. Ten points, due day 14. The question is the title of the week, and
your answer has to come from the traces.
:::

::: scope | Authorization and Scope
Run this only against the practice target this course gives you, using the agent
in your own lab folder and a model on your own computer. A commercial AI service
is never a permitted target, and neither is any system you do not own. See the
Rules of Engagement page in Start Here.
:::

::: directions | Directions
1. Start the practice target. Leave it running in its own terminal window.
2. Send the supplied request five times, one run at a time. Change nothing
   between runs: not the request, not the model, not the settings.
3. Keep the trace from each run. Label them run 1 through run 5.
4. Build a comparison table with one row per run and these four columns: how many
   tool calls the run made, which tools it called in order, whether it reached a
   final answer, and one column you choose yourself.
5. Read the supplied counting script, make the one-line change it asks for, and
   run it on your runs folder. Put the numbers it prints beside your hand count
   and say whether the two agree.
6. Write five ordinary requests of your own, the kind a support worker would
   send. Run each one once. Build a second table the same way.
7. In under 200 words, say what varied across the five same-request runs and what
   held in all five. Name the row or column that shows each one.
8. In two or three sentences, say what one run proves and what your ten runs do
   not settle.
:::

::: callout tip | Two small things that save an hour
Run them one at a time and check that each trace was written before you start the
next. Five runs that all failed the same way take five times as long to sort out.

Name your files so you can tell the two sets apart. Run 1 of the supplied request
and run 1 of your own requests are different runs, and a table that mixes them is
not a table.
:::

::: grading | Grading Criteria
| What earns it | Points |
|---|---|
| Ten runs completed, with a trace kept for each | 2 |
| The five same-request runs compared, filled from the traces | 3 |
| The five requests of your own compared the same way | 1 |
| What varied and what held, each pointing at a row or column | 2 |
| What one run proves, and what ten runs do not settle | 2 |
| **Total** | **10** |

Five runs that came out identical earn full marks when they are described
accurately. You are graded on the comparison, not on what the agent happened to
do.
:::

::: submit | How to Submit
Submit one file. A text file or a PDF is fine. Put your name at the top, then
your answers under the numbered headings from the directions, with both tables in
place. Attach your ten trace files as a second upload, in one folder or one zip
file. Due Sunday 11:59 PM, day 14.
:::
