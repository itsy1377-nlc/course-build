::: intro
Run the agent once, read its record, and list what it can reach. Ten points, due
day 7. This is the first graded work in the course and it sets the habit
everything else depends on: point at the record, not at what the agent said.
:::

::: scope | Authorization and Scope
Run this only against the practice target this course gives you, using the agent
in your own lab folder and a model on your own computer. A commercial AI service
is never a permitted target. See the Rules of Engagement page in Start Here. You
must pass the gate quiz before this assignment will open.
:::

::: directions | Directions
1. Finish the week 1 setup walkthrough. Confirm the check command prints
   **ready** before you go on.
2. Start the practice target. Leave it running in its own terminal window.
3. Send the supplied request exactly as written. Do not change it yet.
4. Find the trace file your run wrote. It is in your lab folder under `runs`.
5. Open the trace and answer, in your own words and in under 150 words: what did
   the agent do, in order? Name each tool it called.
6. Copy the one line from the trace that shows the tool call you think matters
   most. Say why you picked it.
7. Open your agent's tool list. For every tool, write one row: the tool's name,
   one sentence on what it touches, and **yes** or **no** for whether you could
   undo it.
8. Write one sentence naming something this run does not tell you. There is
   always something.
:::

::: callout tip | If you get stuck
Setup is the hardest part of week 1 for most students, and it is not a measure of
whether you belong here. If you pass two hours, stop and post on the Questions
and Answers board with the exact error text. Do not retype the error from memory
and do not post a photograph of your screen; copy the text.
:::

::: submit | How to Submit
Submit one file. A text file or a PDF is fine. Put your name at the top, then
your answers under the numbered headings from the directions. Attach your trace
file as a second upload. Due Sunday 11:59 PM, day 7.
:::
