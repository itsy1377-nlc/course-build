::: intro
This week your own code talks to the model for the first time. A model is the AI service your code sends text to. It reads your text and writes an answer back. You write one function, then watch how it behaves.
:::

What you add this week, and the one thing to watch for.

::: objectives
By the end of this module, you will be able to:

- **1.1** Classify one email using a model call from your own code. (CLO2)
- **1.2** Record how the six answers to one email differ at two temperatures. (CLO2)
- **1.3** Name one thing to check before trusting the model's answer. (CLO2)
:::

::: section | What you add this week
One thing. Your Python code can send text to the model and read the answer back.

That is the whole capability. Nothing is checked yet. Nothing is stored in a fixed shape. You write one function, `ask_model()`, and you use it twice.

Every later week is this same call plus one addition. Week 5 puts the call in a loop and calls the result an agent. An agent is a program that sends text to a model, reads the answer, and acts on it. There is no magic in it. There is a call.
:::
