::: intro
You write your code at **notebook.bashtion.dev**. This page shows you how to open it, how to keep your work safe, and how to move it to another computer.
:::

::: keyfacts
| | |
|---|---|
| Address | notebook.bashtion.dev |
| What you install | Nothing |
| Where your work is saved | In this browser, on this computer |
| How you keep a copy | Download a backup every week |
:::

::: callout warning | Your work is saved in your browser
Nothing you write is kept at the college. It sits in the browser you used, on the computer you used.

Clear your history, switch browsers, or sit at a different machine, and your work won't be there. So back it up every week.
:::

::: steps | Opening a notebook
1. Go to **notebook.bashtion.dev**.
2. Wait. The first load takes about a minute while Python starts. It isn't stuck.
3. In the file list on the left, double-click this week's notebook.
4. Run the first cell. Paste your key on the line it points to.
:::

::: section | Your key
Your instructor gives you a key. It's yours alone, and it carries your own spending limit.

Paste it into the first cell each week. Never put it in a discussion post, an email, or a screenshot.

Any cell can tell you what is left. Run `budget_left()`.
:::

::: steps | Backing up your work
1. Press **Ctrl** and **S** to save. On a Mac, press **Command** and **S**.
2. Run the last cell of the notebook. It builds a backup file and prints its name.
3. Find that file in the list on the left.
4. Right-click it and choose **Download**.
5. Keep it somewhere safe. Your college drive or a USB stick both work.
:::

::: steps | Moving to another computer
1. Open **notebook.bashtion.dev** on the new computer.
2. Drag your backup file into the file list on the left.
3. In any notebook, run `restore_my_work("your-file-name.zip")`.
4. Close the notebook and open it again.
:::

::: section | Two more things
Don't use a private or incognito window. Your work disappears when you close it.

If your instructor posts a fixed notebook, it arrives under a new name. Your own copy is left alone.
:::

::: callout note | If your work is missing
First check that you're on the same computer and the same browser as before.

Then upload your latest backup and restore it. If you've no backup, email your instructor before you redo anything.
:::
