::: intro
This week your own code talks to the model for the first time. A model is the AI service you send text to: you send words, it sends words back. You'll write one small function, then watch it behave.
:::

::: objectives
By the end of this module, you will be able to:

- **1.1** Classify one email using a model call from your own code. (CLO2)
- **1.2** Record how the six answers to one email differ at two temperatures. (CLO2)
- **1.3** Name one thing to check before trusting the model's answer. (CLO2)
:::

::: section | What you add this week
One thing. Your Python code can send text to the model and read the answer back.

That's the whole capability, and if it sounds thin, it is. Nothing is checked yet. You write one function, `ask_model()`, and use it twice.

Every later week is this same call with one thing added. By week 5 it sits inside a loop and we call it an agent: a program that sends text to a model, reads the answer, and acts on it. There's no magic in that. There's a function call.
:::
