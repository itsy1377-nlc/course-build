::: intro
Last week your agent asked for one tool and answered. This week it may go around again, up to four times. After each result it decides what to ask for next. You write the loop that holds those steps, and your code says when the run ends.
:::

::: video w5-overview | What week 5 adds
About four minutes. One step drawn as observe, decide and act, the rule that ends a run early, and the cap that catches the rest.
:::

::: objectives
By the end of this module, you'll be able to:

- **5.1** Build a triage loop with a four-step cap and a stop condition. (CLO3)
- **5.2** Record the tool order and stop reason for six triage runs. (CLO3)
- **5.3** Compare the token cost of a capped run and an uncapped run. (CLO3)
:::
