::: intro
Make the model call your own tool, break it six ways, and say which of your tools
you could undo. Fifteen points, due day 7. This is the first graded work in the
course, and it sets the habit the rest depends on: cite the record, never the
agent's own account of itself.
:::

::: scope | Authorization and Scope
Work only in your own notebook, against the practice target this course gives
you, using a model reached through the school gateway. A commercial AI service is
never a permitted target, and neither is any system you do not own. See the Rules
of Engagement page in Start Here. You must pass the gate quiz before this
assignment will open.
:::

::: directions | Directions
1. Finish the week 1 setup walkthrough. Run the check cell and confirm it says
   your setup is ready.
2. Change the one marked line in the starter function. Then add the decorator on
   the line above it.
3. Run the cell. The filmstrip should show the model calling your tool.
4. Run `show_raw()` under it. Find the line that holds the call, and the field
   inside it that holds the arguments.
5. In under 120 words, write what your agent did, in order. Cite one line and one
   field from the raw record.
6. Now run the six breaks, one at a time: delete the description, describe a
   different function, make it raise an error, make it give back far too much,
   cut the step limit to one, take the tool away.
7. For each break, write one sentence on what changed, and name the line and the
   field that shows it. Run the reset cell between breaks.
8. Add the supplied second tool, the one that writes a file. Run once so it
   appears in your record.
9. For each of your two tools, write three fields: reversible yes or no, the
   reason in one line, and what a person would need to see before approving it.
10. Write one sentence naming something this record cannot tell you. There is
    always something.
:::

::: callout tip | If a break seems to do nothing
Some breaks change less than you expect, and that is a real result. Report it.
"The model called the tool anyway, and here is the line that shows the call"
earns full marks. Writing what you think should have happened earns nothing.
:::

::: callout tip | If you get stuck
Run the reset cell. It puts the known-good version back from any state you can
reach this week. Then run the check cell, which names the fault in one sentence
before the model is called.

If you pass two hours on any one part, stop and post on the Questions and
Answers board with the exact text of the error. Copy the text; do not retype it
from memory and do not post a photograph of your screen.
:::

::: submit | How to Submit
Submit one file, either a text file or a PDF. Put your name at the top, then your
answers under the numbered headings above. Attach your raw record file as a
second upload. Due Sunday 11:59 PM, day 7.
:::
