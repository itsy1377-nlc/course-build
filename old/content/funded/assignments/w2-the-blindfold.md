::: intro
Measure how much one sentence decides. Three grids of thirty trials, two
description edits, and one look at what the model was really sent. Fifteen
points, due day 14.
:::

::: scope | Authorization and Scope
Run this only against the practice target this course gives you. Use your own
agent and the school gateway with the token issued to you. Never a commercial AI
service. Never another student's token. Never a system you do not own. See the
Rules of Engagement page in Start Here.
:::

::: directions | Directions
1. Open the week 2 notebook and run the setup cell. It registers `lookup_a` and
   `lookup_b` with the descriptions as supplied.
2. Run thirty trials with nothing changed. This is your baseline. Save the grid,
   the counts, and the model version the notebook prints.
3. Re-run every errored trial until you have thirty finished ones. Write down
   how many re-runs that took.
4. Change one word in one description. Change nothing else, including the names.
5. Run thirty trials again and save the grid beside the first.
6. Repeat steps 4 and 5 until you have one edit that moved the split and one
   that did not. Keep every grid you run, including the ones you do not report.
7. For each reported edit, give the word you changed, both sets of counts, and
   one sentence saying what a reader may take from the pair.
8. Open the input view on any one trial. Find your two descriptions inside it
   and report the token count on that block.
9. Run `show_raw()` on one trial where a tool ran. Copy the file name, the line
   number and the field that names the tool it called.
:::

::: callout tip | If no edit moves the grid
This happens. It is not a failed assignment. Report three edits you tried,
attach all three grids, and say what the set does and does not support. That
earns most of the credit for that row. What loses credit is claiming a shift
your counts do not show.
:::

::: callout note | If the gateway is unavailable
Your instructor may tell you to use the mock model instead. It picks by a rule
that reads your description, so an edit still moves a grid or does not. The
notebook stamps your file to say a simulator made it. Your written claim has to
say so too. Your reasoning is graded either way.
:::

::: submit | How to Submit
Submit one file, text or PDF, with your name at the top and your answers under
the numbered headings above. Attach your grids as a second upload: the baseline
and both edits, plus any grid you ran and did not report. Due Sunday 11:59 PM,
day 14.
:::
