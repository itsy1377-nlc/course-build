::: intro
The model never reads your code. It reads what you wrote about your code. This
week you measure how much one sentence decides, thirty runs at a time.
:::

::: objectives
By the end of this week you will be able to:

1. Run one request thirty times and read the grid it fills in.
2. Change one word in a tool description and report what moved.
3. State what a grid that did not move does and does not support.
4. Open the model's actual input and find your own words inside it.
:::

::: scope | Authorization and Scope
You may work with three things this term, and nothing else:

1. The practice target this course gives you.
2. The agent you build.
3. The school gateway, using the token issued to you.

Never a commercial AI service. Never a system you do not own. Never another
student's token. Read the Rules of Engagement page in Start Here before you run
anything, and follow it while you run.
:::

::: callout time | How long this should take
| Part | Hours |
|---|---|
| Reading | 1.0 |
| The baseline grid | 1.5 |
| The edit that moves it | 2.0 |
| The edit that does not | 1.0 |
| The input view and the write-up | 1.5 |
| **Total** | **7.0** |

Students new to programming often take two to three times as long on the parts
with code in them. That puts a realistic week between about 10 and 20 hours.
Much of this clock is waiting on runs rather than typing. Start a grid, then
read while it fills.
