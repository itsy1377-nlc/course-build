::: intro
This week you run an AI agent before anyone explains it to you. Then you answer
two questions about what you saw. Those two questions shape the whole course.
:::

::: objectives
By the end of this week you will be able to:

1. Describe what an agent did on one run, using its recorded log.
2. List every tool your agent can reach, and mark the ones you cannot undo.
3. State what you are allowed to attack in this course, and what you are not.
:::

::: scope | Authorization and Scope
You may work with three things this term, and nothing else:

1. The practice target this course gives you.
2. The agent you build.
3. A language model running on your own computer.

Never a commercial AI service. Never a system you do not own. Read the Rules of
Engagement page in Start Here before you run anything. The gate quiz checks that
you have.
:::

| Part | Hours |
|---|---|
| Setup | 1.0 to 2.0 |
| Reading | 1.5 |
| The first run | 1.0 |
| The tool list | 1.5 |
| **Total** | **5.0 to 6.0** |

Students new to programming often take two to three times as long on setup. That
puts a realistic week between about 10 and 15 hours. If setup passes two hours,
stop and post on the Questions and Answers board. Being stuck is normal and it is
not a reason to fall behind.
