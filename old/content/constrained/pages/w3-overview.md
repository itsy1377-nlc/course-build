::: intro
This week you write the attack. You hide an instruction inside data the agent
reads, say what you think will happen, then run it five times and score what
the records show.
:::

::: objectives
By the end of this week you will be able to:

1. Write a case file that plants an instruction in data your agent reads.
2. Predict a result in writing before you run it.
3. Score how far an attack got, using your own trace records.
4. State what a run with no hits does not settle.
:::

::: scope | Authorization and Scope
Your attack runs against three things and nothing else:

1. The practice target this course gives you.
2. The agent you build.
3. A language model running on your own computer.

Never a commercial AI service. Never a system you do not own. Your case file
carries one line saying the target is authorized, and the runner will not load a
case without it. Read the Rules of Engagement page in Start Here first.
:::

::: callout time | How long this should take
| Part | Hours |
|---|---|
| Reading | 1.5 |
| Your case file and prediction | 1.5 to 2.0 |
| Running five trials | 1.0 |
| Scoring the traces | 2.0 to 2.5 |
| **Total** | **6.0 to 7.0** |

The case file is settings, not code, so nothing here asks you to write Python.
Even so, students new to programming often take two to three times as long on
the case file and the trace reading. That puts a realistic week between about 10
and 20 hours. If one step passes two hours, post on the Questions and Answers
board.
