::: intro
This course is seven weeks long and it moves. These are the habits that keep
students in it. None of them is about being clever.
:::

::: section | Start the week on the day it opens
Each week opens on its first day and closes Sunday at 11:59 PM. Open it early,
even for ten minutes.

1. Read the overview page. It lists the tasks and an honest time estimate.
2. Read the content page.
3. Open the assignment before you run anything.
4. Run things early in the week. Leave the writing for later in the week.

A week you start on Saturday is a week you will not finish.
:::

::: callout tip | Setup is the hard part, and it lands in week 1
Students new to programming often take two to three times as long on setup. That
is planned for, and it measures nothing about you. If one step passes two hours,
stop and post on the Questions and Answers board.
:::

::: section | Keep every record you produce
Every run writes a record. Keep all of them, in one folder per week.

The evidence file at the end is built from work you already did: your traces,
your results, your reports. Students who kept their records write it in an
evening. Students who did not have to run everything again.
:::

::: section | A dull result is a full credit result
You are graded on how well your answer matches the record. You are not graded on
whether your attack worked.

An attack that got nowhere earns full marks when you report it accurately. So
does a control that held nothing. Say what the record shows, and say what it
does not settle.
:::

::: section | Write while you work, not after
Keep a plain text file open while you run things. Note what you ran, what came
back, and where the record landed.

Notes written days later are guesses. You will not remember which run produced
which file, and the file is the thing that earns points.
:::

::: section | Two more that cost you nothing
- Read the wrap-up page at the end of each week. It answers the week.
- Read your feedback before you start the next assignment. The same habits are
  graded every week, so one fix earns points seven times.
:::
